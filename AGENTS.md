# Project instructions for coding agents

Read `PRD.md` before proposing or implementing changes. Its scope, data contracts,
cost limits, acceptance criteria, and explicit decision gates take precedence
over generic workflow advice in the installed skills.

This project uses the skills in `.agents/skills/` for Copilot CLI and Codex CLI.
Use applicable skills without adding unrelated artifacts or expanding the
hackathon scope. Use Copilot CLI or Codex CLI to develop the application; the
LiteLLM proxy is for the application's server-side inference only. Never
commit proxy credentials or expose them to the browser.
